# Personal Finance and Expense Analysis Dashboard 💰

## 1. Overview
A data analysis project focused on cleaning, categorizing, and summarizing raw personal financial transactions to derive actionable insights into spending habits, budget adherence, and monthly cash flow.

### 🎯 Goal
The objective was to transform messy banking statements into a structured analytical dataset, enabling reliable monthly and categorical expense tracking for better personal financial planning.

## 2. Tools & Technologies
- **Data Structuring:** Microsoft Excel, Data Validation, Pivot Tables
- **Analysis:** Categorization (Living Expenses, Discretionary, Transport), Monthly Roll-up, Top-N Analysis
- **Visualization:** [Mention Power BI, Tableau, or Excel Charts, depending on your final output]

## 3. Key Actions / Process (Data Cleaning & Modeling)
- **Data Ingestion & Cleaning:** Consolidated transactions from multiple accounts (UPI, Debit Card) and applied consistent formatting and date logic.
- **Categorization:** Developed a **3-Tier Categorization Model** (Category Type $\rightarrow$ Category $\rightarrow$ Sub-category) using Excel's **Data Validation** to ensure standardized tracking across all 12 months.
- **Pivot Analysis:** Created dynamic Pivot Tables to calculate monthly totals for Income, Expenses, and specific categories, facilitating rapid time-series analysis.
- **KPI Calculation:** Tracked key metrics like Net Monthly Cash Flow and Identified **Top 5 Expense Categories** (e.g., Rent, MV Loan, Entertainment).

## 4. Key Achievements & Results
- **Data Integrity:** Established a sustainable and reliable **data cleaning and categorization template** for ongoing use, ensuring data integrity across different financial sources.
- **Insight Generation:** Identified major spending drivers, enabling the user to optimize spending in high-cost categories (e.g., Dining Out, Coffee).
- **Efficiency:** Used Pivot Tables to quickly perform comparative analysis (Month-over-Month) without needing complex formulas, streamlining the monthly review process.
